# Speaking Test Timer

Static webpage for IELTS Foundation speaking practice — Course 34. Randomly displays one of 20 questions with two countdown timers.

## How to use

1. Open the page: https://anhnd2102.github.io/speaking-test-timer/
2. Click **Random Question** (or press `R`) to show a random question
3. The Preparation timer (30s) starts first — press `Space` or click Start
4. The Answer timer (60s) starts next — press `Enter` or click Start
5. When preparation time ends, the answer timer auto-starts

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `R` | Pick a new random question |
| `Space` | Start / Pause preparation timer |
| `Enter` | Start / Pause answer timer |
